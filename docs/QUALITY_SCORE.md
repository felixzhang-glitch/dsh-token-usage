# 质量评分

> 每维度 0-5 分。初始化时按现状打分作为基线，重大变更后复评并记录日期

| 维度 | 分数 | 说明 |
|---|---|---|
| 可测试性 | 2 | 无自动化测试框架；验证路径成熟（node --check / pack 演练 / 沙盒安装 / 实机验证），历史需求均带验证记录 |
| 文档完整度 | 4 | README / AGENTS.md / design / architecture / requirements / plugin-guide 齐全且随迭代更新；产品、安全、可靠性、测试维度齐备 |
| 代码规范 | 3 | 零三方依赖纪律、语法检查常态化、依赖契约显式声明；无 linter / formatter 强制 |
| 可靠性 | 4 | 分发与回滚移交官方 plugin-manager 托管（失败自动恢复 manifest/lockfile）；本地通道 link 活链接改码即生效 |
| 安全性 | 3 | 本地自用、不碰凭据、零运行时依赖、分发面 files 白名单收敛；路由无鉴权（接受为已知风险） |
